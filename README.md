# Kanban Board — Test Task

Канбан-доска с задачами из JSON: 4 колонки по статусам, сортировка, удаление, подсветка просроченных, поиск и drag&drop.

:eyes: [Реализация](https://sherrasy.github.io/kanban-test/) 

## Запуск

```bash
# установка зависимостей 
npm install

# dev-сервер (http://localhost:3000)
npm run start

# production-сборка
npm run build

# unit-тесты
npm run test
```
