# Kanban Board — Test Task

Канбан-доска с задачами из JSON: 4 колонки по статусам, сортировка,
удаление, подсветка просроченных, поиск и drag&drop.

## Технологии

- **Webpack 5** — сборка и dev-server
- **React 18** — UI
- **TypeScript 5** — типизация (strict)
- **Jest + Testing Library** — unit-тесты
- **CSS Modules** — стили
- Node.js **18.18.0**

## Запуск

```bash
# установка зависимостей (рекомендуется npm ci по lock-файлу)
npm install

# dev-сервер (http://localhost:3000)
npm run start

# production-сборка
npm run build

# unit-тесты
npm run test
```
